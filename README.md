
## FVTTD35E-CN
（#正在编辑中）
这是基于FVTT上由Rughalt所制作的srd-d35e系统创建的汉化版系统。
此系统致力于尽可能完整的中文化，并在现有系统上修复bug、完善系统内容，在数年更新以来，已经完善了比原版更多的功能。
系统为全覆盖式安装，与原系统不兼容，但内容兼容。
 当前适配的FVTT版本为Version 11 Stable（也就是V11）构建315
 而35E系统基底为2.4.3，目前进行了大量修改。
 

## 安装系统
目前系统考虑到版权问题没有集成到FVTT中，因此需要手动安装。
1. 点击右侧的Releases版本版本，下载Source code(zip)文件，到本地右键解压到当前文件夹，然后将解压出来的文件夹改名为“D35E”
2. 打开fvtt的系统目录，通常是：C:\Users\你的用户名\AppData\Local\FoundryVTT\Data\systems。
3. 将解压后的文件夹复制到此目录中，如果你已经有安装D35E系统，那么建议将原本的删除，然后再复制进去便安装完成。
#### 注意！如果你曾自己在系统合集中加入过内容，此过程会导致内容丢失！若要避免此类情况请看下方说明。

你曾经写过自己的内容并且放入了合集包：
如果内容不多，通常建议你直接将做好的内容拖动到世界包内备份，然后替换更新
但如果内容太多，那么在覆盖汉化前你需要先打开系统根目录下的pack文件夹，这其中是你此系统的合集文件，将对应类别拷贝出来
然后删除你原有的d35E文件夹并将汉化系统放入文件夹，
再打开汉化后系统的pack文件夹，将你覆盖类型的合集文件夹删除，然后再将你拷贝出来的带有你自己资源的文件夹复制进此目录便可安全替换完成。

## 常见问题
**问**：为什么要留在V11？为什么不跟进最新的V13或V14?<br>
**答**：这其中原因很多样，这个系统原本从fvtt里的PF系统改造过来，并使用了一部分5e系统的代码，但V12更新时，许多底层都被打破，使得此系统必须彻底重构，所以没有升级上去；其次，原作者也停更了许多年，在此期间，我独自修复这个系统，优化UI，实际上它就是一坨bug跑起来的未知聚合体，在一个连函数名字都能写错的代码堆里，你永远也不知道有什么雷等着你，作者的新版本这些问题显然都没修，我也没精力再去修一遍原版系统；最后也是最重要的一点，V11的功能已经足够完善，除非你是想玩3Dmod之类，否则作为跑团工具它已经完全足够使用了。




问：会改动我已有世界包里的东西吗？<br>
答：不会改动合集以外的内容，但部分专长，例如猛力攻击和双武器攻击等可能失效，改为汉化后的版本即可正常生效。




**问**：目前系统能自动化吗？<br>
**答**：现在已有较高程度的自动化：除开数值自动计算，现在还可以自动计算攻击、豁免，自动应用效果，而这些可以被一个灵活的开关随时切换，如果你不喜欢，也可以在系统设置里关闭。




**问**：有特效吗？<br>
**答**：系统内置了一个非常轻量的动画效果，基于近战、远程、法术、buff类能力创建，并支持不同能力变体，而如果你想要更复杂的自定义效果，你可以关闭系统内置的特效，启用模组AA（autoanimations）。




**问**：目前系统内置有哪些内容？<br>
**答**：srd3.5e的大部分内容，以及扩展大全2.1为止的所有法术、灵能、专长、魔法物品，其中大部分以AI自动导入并实现了简单自动化，但不保证完全没故障。




**问**：为什么职业这么不完整？<br>
**答**：因为职业只能一个个手动做，加上还有法表、资源等问题，一个人做力不从心。




**问**：与mod兼容性如何，扩展性大吗？有推荐吗<br>
**答**：因为处于已经普遍停更的V11版本，此模组已经内置了以下mod，你不应当重复安装它们：Socketlib（仅作为依赖）,Drag ruler,notbook,Monk`s token bar,CautiousGamemastersPack，dice-calculator（Tray-dice）。




**问**：我不会用这个系统，我该去哪里学？<br>
**答**：系统初次打开会带有一个可视化的教程，此教程已经汉化，能满足最初的学习，在那之后你可以在文件根目录找到译者非瑞克西亚发布一份教程文档，它会提到更多细节。你可以加入fvtt3r的qq群：808945118

## 功能更新：
-装备页现在有穿戴部位（高版本同款）<br>
-现在token可自动计算夹击，可开关功能（高版本同款）<br>
-在拖动token移动时，自动计算距离（内置Drag ruler模组）<br>
-现在新增了一个编写的笔记窗口，可以用各种便捷的模板来储存你的小抄（内置Notbook模组）<br>
-内置一些小功能，例如编辑聊天、显示有人正在输入文本。（内置CautiousGamemastersPack模组部分功能）<br>
-内置了聊天染色，锁定角色发言等功能（内置chat-portrait模组）<br>
-内置了导入VTT格式的模块（内置dd-import模组）<br>
-内置了在聊天窗口上添加骰子的功能（内置Tray-dice）<br>
-新增了1个可以锁定玩家移动、发起投骰的便捷面板，此外，此内置修复了它无法抓取到数据自动检定成功失败的问题，而且现在在发起检定时，可以将检定窗口直接弹给玩家（内置monk`s token bar模组）<br>
-现在新增了触及范围数值，默认为5，可通过特性变化。触及影响token的借机距离，处于所选token威胁的单位会被染色，也可系统里更改为威胁范围模式<br>
-现在战斗中，从触及范围里移动的token会被提示借机，可以借机的角色会在聊天获得提示，并自动弹出可选攻击项窗口。此功能可在系统关闭。此外，可通过角色的右上角一个开关来避免被借机。此外，变化里新增了一个借机次数，用于统计每轮可用借机。<br>
-新增自动结算功能，在锁定了目标的情况下，使用武器攻击，或是以伤害法术的模板框选token时，会自动结算AC、豁免、伤害，通过选中token按‘Y’键或是角色卡右上角一个开关，可以开关此token受到的自动结算，此外，为此新增了能力不会伤害友军的开关。<br>
-新增了攻击的‘反击’词条，在受到攻击伤害后可自动对攻击者进行反击，可用于制作自动化的罗比拉战术、火焰护盾等效果。<br>
-现在内置了简易动画，武器攻击会有通用命中动画，当token受伤时会有音效+受击反馈，每个token可单独配置，可在系统设置关闭。<br>
-现在会在选中的token和锁定的token之间显示一条所有人可见的流光连线，可在系统里关闭。<br>
-优化了战斗追踪器的动作结算，现在它会自己统计使用掉的动作，不过仅仅只是显示，不会阻止角色使用能力。<br>
-新增一个宏命令，可让GM向所有玩家发起‘直觉时机’，当玩家战斗追踪器还有直觉动作剩余，且角色里还有可用的直觉能力、法术、装备时，向他推送窗口，显示所有可用直觉选项。<br>
-重构全力攻击指令，现在可自由手动配置攻击次数、减值（不会自动计算那些全力攻击的减值），使用后会弹出汇总攻击窗口，可以选择在此勾选能力或是填写额外数值，而后让所有攻击都以这些调整自动发起攻击，当然，也可以关闭自动投掷来一个个弹出攻击。如果攻击者在全力攻击中死亡，自动全力攻击会自己中止。<br>
-新增一个宏命令，在锁定了目标时，可以选择多个token，一起向目标发起攻击，它们所有可用的攻击都会显示出来，并可以单独配置加减值，和将要使用的攻击。<br>
-光环能力得到重构，现在它拥有一种可以设置对特定角色生效的模式，而非临时计算（这会有严重性能问题），此外，光环的能力将时刻和主人同步，而且光环现在可以和专长类物品一样设置变化、战斗行动。<br>
-新增一个宏命令，用于快速切换所选token的自定义词条。<br>
-远程武器使用的弹药现在会被记忆，无需每次攻击都重新选。<br>
-重做了容器，现在容器可以被打开，方便地将物品拖进去，并在多个角色之间复制。<br>
-重做了数据卡生成功能，现在你可以一键将整个角色导出成纯数据卡，用于fvtt以外的环境。<br>
-重做了专长和职业能力页面，现在更便于管理数量庞大的专长和职业能力。<br>
